# WebSim
Responsive preview tool — plain HTML, CSS and vanilla JS. No dependencies, no build step.

1. Unzip and open `index.html` in a modern browser (Chrome, Edge, Safari, Firefox).
2. Import a ZIP, HTML/CSS/JS files or a folder.
3. Pick a device, drag the width slider, run Responsive Check.

Projects stay in your browser (IndexedDB). Devices are simulated viewport profiles, not exact hardware emulation. The health score is a heuristic, not a guarantee.
